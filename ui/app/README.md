# WorkLedger Enterprise Frontend Foundation

This directory contains the structured G4 frontend foundation.

- index.html — accessible application entry point
- styles.css — design tokens, layout, responsive rules, and shared component styles
- fixtures.js — deterministic local context, roles, navigation, and task fixtures
- app.js — capability-aware shell, role preview, navigation, and fixture-first views

Open index.html directly in a browser. It uses no backend, network, package installation, or external service.
